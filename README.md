# hallmark

Design new websites, landing pages and web UI screens that look designed, not generated. Use when asked to build or design a new page/site, or when Hallmark is named; never on an existing design unless named.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-hallmark.git ~/.claude/skills/hallmark
```
